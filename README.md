# Japanese Verb Flashcards

Phone-first flashcards for 200 common Japanese verbs (N5/N4), built for Louis.

**Live:** https://alt-f17.github.io/japanese-verb-flashcards/

- Front: dictionary form with reading (`食べる｜たべる`) and polite form (`食べます`). Tap to flip to the English.
- ✓ Correct takes the card out for the round. ✕ Incorrect puts it back later in the deck.
- Four decks of 50 (Core verbs, Daily life, Home/town/travel, Thoughts/feelings/people) or all 200 at once.
- Shuffle, progress, completion screen and Reset Deck.

Plain HTML/CSS/JS, no build. Run locally with `npm start` (then open http://localhost:8000), test with `npm test`.
